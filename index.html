Projects

Web Application – Manual QA and Test Automation

I performed quality assurance for a fully developed web application, working collaboratively within an Agile Scrum environment. The team operated in weekly sprints using Jira to manage tasks and participated in ceremonies such as Sprint Planning, Daily Stand-ups, and Sprint Reviews.

I designed test cases for user stories using the BDD methodology, based on clearly defined acceptance criteria. Test scenarios were written in Gherkin and managed with AssertThat to maintain traceability between requirements, tests, and results within Jira. Tests were executed across both web and mobile environments.

Throughout each sprint, I performed functional testing and conducted exploratory testing at the end of the sprint to identify defects not covered by predefined test cases. All defects were reported in Jira and linked to their corresponding user stories to ensure full traceability.

At the end of each sprint, I contributed to the release preparation in Jira and documented all relevant information in Confluence, including the test plan, execution results, and overall product quality status.

After the release, I identified the main application flows and automated the regression tests using Playwright and Pytest with Python. These automated tests were integrated into a continuous integration pipeline using GitHub Actions, configured to run weekly regression suites aligned with sprint closures.

QA Portfolio – Web Development & API Testing

I developed a personal QA portfolio using HTML5, CSS3, and JavaScript, integrating a contact form connected to an API built with Supabase. I designed the database tables and performed SQL queries to insert and retrieve test data.

I carried out API testing using Postman, creating tests for GET, POST, PATCH, and DELETE requests. The tests validated positive and negative response codes, authentication behavior, and the correctness of the JSON structure and content.

Additionally, I implemented a continuous integration workflow using GitHub Actions, configuring Newman to automatically execute the Postman test collection on every repository update.
